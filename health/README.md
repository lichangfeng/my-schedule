# 轻养记录

一个不需要账号、数据保存在手机本机的体重与饮食记录页面。

## 功能

- 记录每日体重和饮食
- 一键复制当天饮食给豆包
- 粘贴豆包返回内容后自动识别热量和三大营养素
- 每日营养目标按最新体重和 g/kg 比例自动计算
- 体重趋势图、目标进度和历史记录
- 本地保存、JSON 导出/导入
- 一键检查更新
- 可添加到手机桌面，离线打开

## 手机直接打开

双击“启动手机页面.cmd”，然后让手机和电脑连接同一个 Wi-Fi。

当前局域网地址：

    http://192.168.31.123:8776/

如果电脑 IP 改变，启动脚本会显示新的地址。

## 在电脑预览

在当前目录打开终端，运行：

    python -m http.server 8775 --bind 127.0.0.1

然后打开：

    http://127.0.0.1:8775/

## 手机访问

手机和电脑连接同一个 Wi-Fi 后，用电脑的局域网 IP 访问同一端口，例如：

    http://192.168.1.10:8775/

需要让服务器监听局域网：

    python -m http.server 8775 --bind 0.0.0.0

如果手机打不开，请检查 Windows 防火墙是否允许 Python 的局域网访问。

## 更新页面

修改 index.html、styles.css 或 app.js 后，在手机页面点右上角刷新按钮。记录保存在 localStorage，不会因为刷新而清空。

## 数据说明

- 数据保存在当前网址对应的浏览器 localStorage 中。
- 同一网址、同一浏览器再次打开时会保留记录。
- 换端口、换局域网地址或换浏览器会看到另一份数据。
- 清理浏览器网站数据前，请先在“设置”中导出备份。
